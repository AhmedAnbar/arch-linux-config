# Logo

File: `logo.png`. The prompt below was written by the codex CLI (`codex exec`).
Ahmed generates the image from it in ChatGPT and saves the result as
`assets/logo.png`, which the README header references. Export at 512 px: the
header renders at 240 px, and a 1254 px original costs five times the page
weight for no visible gain.

Prompt:

Create an original minimalist logo for a personal Arch Linux i3 and Sway desktop configuration project called Arch Linux Config, a large centred Arch counterpart to a geometric mountain-shaped symbol, constructed from three rounded tiled window panels with clear visible gaps and a tiny angular terminal prompt accent, using flat crisp shapes in Catppuccin lavender #b4befe with subtle lighter Catppuccin sky #89dceb highlights on a solid dark #1e1e2e background, preserve the visual language of the sibling Debian project with generous margins, strong geometric balance, clean edges, and clear readability at small README icon size, use only straight, angular, block-like, or sharply segmented accent forms, include no spiral, swirl, curl, comma, teardrop, loop, coil, ribbon, flowing curve, or any curved flowing shape anywhere in the mark, do not place decorative symbols inside the panels that could suggest a distribution emblem, keep the three-rounded-panel mountain arrangement unmistakable, use a rounded triangle on top and two rounded trapezoid panels below it with clear gaps, apply flat solid fills, add small angular lighter sky highlights in the upper-left corner of each panel, include the same small angular terminal prompt mark in the right panel, include no text, no lettering, no watermark, and ensure the mark is entirely original and does not replicate, imitate, or closely resemble the official Arch Linux logo or any official distribution logo

This replaces the first prompt, whose image had a white background, a notched
peak and the prompt accent in the left panel. The sibling repository
[debian-like-config](https://github.com/AhmedAnbar/debian-like-config) uses the
same paragraph with Debian red #A80030 and a coral highlight, so the two marks
read as a pair.
